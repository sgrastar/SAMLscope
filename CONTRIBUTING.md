# Contributing

Use a Signed-off-by line to certify the Developer Certificate of Origin; no CLA
is required. Original software and test-code contributions are submitted under
Apache-2.0. Original narrative, requirement/test-definition explanations and
profile mappings you have the right to license are submitted under CC BY-SA 4.0.
See `LICENSING.md` for the material boundaries.

Record the author, copyright notice, exact document edition, URL, license or
permission text, modifications and intended location of third-party material.
Do not apply the project's licenses to material you cannot license on those
terms. Mixed documents retain their third-party terms and attribution.

Never manually edit generated files or change signed G1/G2 artifacts without the
existing independent approval process. Run `dev/licensing/materials.py --check`
with the repository Python environment when changing catalogs or licensing inputs.
